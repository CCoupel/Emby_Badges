# Release v1.2.0 - Vos affiches gagnent une note, et les séries aussi

**Date** : 2026-09-25

## Nouveautés

### La note, en un badge
La note communautaire s'affiche directement sur l'affiche, sans ouvrir la fiche.

### Séries et saisons aussi
Les badges couvrent désormais les séries et les saisons, avec les épisodes cumulés.

### Vignettes paysage badgées
Les vignettes paysage des épisodes, comme dans « Reprendre la lecture » sur l'accueil, affichent leurs badges.

## Comment mettre à jour

Remplacez `EmbyBadges.dll` à la racine du dossier `plugins/` d'Emby, redémarrez Emby, puis videz le cache d'images pour voir les nouveaux badges.
