# Doc-updater — adaptations Emby_Badges

Compagnon de `doc-updater.template.md` : les règles ci-dessous **prévalent** sur le template.

- **Pas de `CHANGELOG.md`** (décision projet maintenue) : ne pas le créer. Les changements d'une version sont
  consignés dans les release notes `docs/releases/vX.Y.Z/` et dans `README.md` ; la Release GitHub (CI) en tient lieu.
- `CLAUDE.md` reste la source de vérité technique (architecture, cache key, badges) : le tenir à jour à chaque feature.
